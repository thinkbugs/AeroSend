## 2. 逐页核对

### 2.1 设备页（Dashboard）

UI Automation 文本：`面向 Windows 的 AirPlay 投屏工具`、`扫描设备`、`已发现设备`、`系统状态`、`视频编码`、`投屏协议`、`手动添加设备`、`IP 地址（例如 192.168.1.100）`、`端口`、`名称（可选）`、`添加`、`可用设备`；设备卡片显示 `AirPlay 镜像` / `AirPlay 音频`。

## 4. 未翻译的部分

- **协议与采集深层错误链**（anyhow 上下文，例如 RTSP 状态码、DXGI 初始化失败、ffmpeg 报错）仍为英文。它们是排障信息，翻译会切断与日志、源码、上游文档的对应关系；出现在错误条时会与中文前缀混排，这是有意保留。
- 设备名、渲染器名、型号来自对端广播，原样显示。
- `console.error` 等开发者日志不翻译。
- 托盘菜单未实际点开验证（见 2.5）。
